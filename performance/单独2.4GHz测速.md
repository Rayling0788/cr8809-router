# 单独 2.4 GHz 校园 Wi-Fi 下载测速

测试下载全部固定到 phy0-sta0（wwan3），16 个 HTTPS 连接，约 35 秒，无客户端限速。其他日常流量保留原双线出口。

- 测试下载平均：5.05 MB/s。
- 测试下载连续约 5 秒峰值：6.37 MB/s。
- 下载连接错误：0。
- 已核对专用分流规则命中 32 个新连接包，使用 0x400 标记和路由表 4，经 phy0-sta0 发送。
- 测试后删除临时规则，恢复 campus、wireless、mwan3，逐字核对通过。

这是当前校园网络和背景负载下的有效下载速度，不是 Wi-Fi 协商速率或硬件绝对上限。MB/s 采用十进制。
